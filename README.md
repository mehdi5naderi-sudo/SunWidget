# SunWidget

ویجت اندرویدی نمایش طلوع و غروب خورشید.

## امکانات
- نمایش ساعت طلوع و غروب خورشید
- گرافیک آسمان روز/شب و موقعیت تقریبی خورشید/ماه
- استفاده از موقعیت مکانی گوشی؛ در صورت نبود موقعیت، تهران به‌عنوان پیش‌فرض
- دریافت اطلاعات روزانه از Sunrise-Sunset API
- به‌روزرسانی خودکار ویجت هر ۳۰ دقیقه
- با هر Push روی `main`، GitHub Actions نسخه جدید APK را می‌سازد و در Releases قرار می‌دهد

## نصب
1. آخرین Release را از GitHub دریافت کنید.
2. APK را نصب کنید.
3. برنامه «طلوع و غروب» را یک‌بار باز کنید و اجازه Location بدهید.
4. ویجت را به صفحه اصلی اضافه کنید.

> نکته: نسخه فعلی برای تست به‌صورت Debug ساخته می‌شود. برای اینکه APKهای بعدی بدون حذف نسخه قبلی نصب شوند، باید یک کلید امضای ثابت GitHub Actions تنظیم شود.
